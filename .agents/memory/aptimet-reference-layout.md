name: AptiMet reference layout
description: Visual constraint for the trainee dashboard reference image.
---

The trainee dashboard's defining composition is a compact two-column content area with the announcements rail visible at laptop width, not only on wide desktop screens.

**Why:** The supplied reference is a 954px-wide laptop view; deferring the rail to a wide breakpoint removes a key part of the intended screen.

**How to apply:** Keep the rail and enrolled-course pair active at laptop widths, then let the layout collapse only for genuinely narrow/mobile screens.
